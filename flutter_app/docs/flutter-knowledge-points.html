Project Knowledge Map

Daynote Flutter App
知识点地图

该项目不是基础示例，而是一个 iOS 优先的个人助理客户端，覆盖账户、语音、AI 任务、本地数据、原生提醒和 App Store 合规等完整移动应用链路。

Flutter / Dart Material 3 REST API 语音识别 Swift / MethodChannel AlarmKit
16个核心知识领域
3种会话状态：未登录、访客、正式账户
4类生活记录：行程、账单、备忘、心愿
01

Dart 语言基础

  • 类、命名参数、空安全、枚举、Getter 和 Factory 构造函数。
  • JSON 序列化与反序列化、可选字段和 copyWith。
  • map、where、fold 等集合操作。
  • Dart 3 Record、Switch expression 和模式化数据组织。
  • Future、async/await、Completer、异常和超时。

对应文件：lib/models.dart

02

Flutter 应用与组件生命周期

  • main、runApp、Flutter Binding 初始化和竖屏锁定。
  • StatefulWidget、StatelessWidget、initState、build、dispose。
  • 异步操作后的 mounted 检查和资源释放。
  • 应用启动时恢复本地会话，再决定显示登录页或主页。

对应文件：lib/main.dart

03

状态管理与交互状态

  • 当前采用 Flutter 原生 setState，没有引入 Provider、Riverpod 或 Bloc。
  • 登录、加载、错误、录音、识别、后台处理等多状态组合。
  • 父子组件回调、状态提升和 revision 驱动子页面刷新。
  • 乐观更新：先更新 UI，请求失败后恢复旧数据。
  • 利用 _disposing 避免销毁后的异步状态更新。
04

Material 3 UI 与移动端布局

  • 主题、ColorScheme、Scaffold、Dialog、SnackBar、Bottom Sheet。
  • SegmentedButton、DatePicker、RefreshIndicator 和进度状态。
  • SafeArea、LayoutBuilder、Expanded、ListView 和滚动布局。
  • 卡片、空状态、错误提示、窄屏溢出处理与中文字体回退。
  • 按住录音、松开提交的 Pointer 交互。
05

登录、会话与安全存储

  • 邮箱验证码登录和客户端输入校验。
  • signedOut、guest、signedIn 三种会话状态。
  • Bearer Token、会话恢复、失效处理和退出登录。
  • 通过 flutter_secure_storage 使用 iOS Keychain 保存凭据。
  • 账户删除二次确认以及删除后的本地凭据清理。

对应文件：lib/api_client.dart、lib/main.dart

06

HTTP、REST API 与错误处理

  • 使用 http 包完成 GET、POST、PATCH、DELETE。
  • JSON 编解码、HTTP 状态码、自定义 ApiException。
  • 网络异常转换成适合最终用户阅读的中文提示。
  • 通过 --dart-define=API_BASE=... 注入环境地址。
  • 以 application/octet-stream 上传音频二进制数据。

对应文件：lib/api_client.dart

07

访客模式与本地持久化

  • 使用 SharedPreferences 保存访客记录和知识库 JSON。
  • 本地 Upsert、删除、完成状态更新和损坏数据容错。
  • 访客登录正式账户后，将本机数据自动迁移到云端。
  • migrationId 支持服务端实现幂等迁移。
  • 利用 Future 链和 Completer 串行执行写操作，减少竞争条件。

对应文件：lib/guest_store.dart

08

业务数据建模

  • 行程、账单、备忘、心愿和个人知识库。
  • 金额、分类、时间范围、优先级、完成状态和提醒时间。
  • 日报、周报、月报以及亮点、改进、建议三类报告内容。
  • UTC 与本地时间互转、ISO 8601 格式和后端字段兼容。
09

日期、时间与国际化

  • intl、DateFormat 和中文日期符号初始化。
  • zh_CN Locale 与 Flutter Material 本地化代理。
  • 日期选择、前后日期切换、同日判断以及日周月范围计算。
  • 服务端 UTC 时间和设备本地时区之间的转换。
10

语音录制与文件处理

  • 麦克风权限和设备编码器能力检查。
  • WAV、16 kHz、单声道、回声消除与降噪配置。
  • 临时音频文件创建、读取、长度检查和最终清理。
  • 按住开始、松开结束、短按拦截、取消录音和资源释放。
  • 上传音频并获取语音转写文本。

对应文件：lib/voice_service.dart

11

AI 意图识别与异步任务

  • 将自然语言自动分类为记录、知识保存或知识问答。
  • 处理 HTTP 202、Job ID 和 COMPLETE / FAILED 任务状态。
  • 定时轮询、任务超时和后台继续处理。
  • 录音转写与 AI 分类拆分成连续异步阶段。
  • Pending Task 列表让用户看到每条语音当前所处阶段。
12

统计报告与缓存策略

  • 日报、周报、月报的时间范围筛选和客户端统计。
  • 支出合计、记录数量、待办完成率。
  • 缓存报告、stale 标记和 refreshJobId。
  • 先展示旧缓存，再后台刷新，属于 Stale-While-Revalidate 思路。
13

Flutter 与 Swift 原生通道

  • 使用 MethodChannel 从 Dart 调用 iOS 提醒能力。
  • Dart Map 与 Swift Dictionary 之间的数据传递。
  • Plugin Registrar、Flutter implicit engine 和 FlutterError。
  • 通道名称：com.from2033.assistant/reminders。

对应文件：lib/reminder_service.dart、ios/Runner/AppDelegate.swift

14

iOS 通知、AlarmKit 与工程配置

  • UserNotifications 权限、调度、同步删除和前台展示。
  • iOS 26 AlarmKit、固定时间闹钟及普通通知降级方案。
  • Swift Concurrency、Task、DispatchGroup、NSLock 和主线程回调。
  • @available 与 #if canImport 的系统兼容处理。
  • Info.plist、SceneDelegate、Bundle ID、签名、版本号、xcconfig 和 AppFrameworkInfo。

对应文件：ios/Runner/AppDelegate.swift、ios/Runner/Info.plist、ios/Flutter/AppFrameworkInfo.plist

15

隐私与 App Store 合规

  • 麦克风和 AlarmKit 权限用途说明。
  • Privacy Manifest 声明邮箱、用户 ID、音频和用户内容。
  • 声明数据仅用于 App 功能且不用于跟踪。
  • 非豁免加密声明、隐私政策链接和 App 内账户删除。

对应文件：ios/Runner/PrivacyInfo.xcprivacy、ios/Runner/Info.plist

16

测试与代码质量

  • Flutter Test 单元测试和 Dart 静态分析。
  • 模型 JSON 解析、时间范围、提醒和报告数据测试。
  • 访客记录与知识的 JSON round-trip 测试。
  • flutter_lints 推荐规则。

对应文件：test/models_test.dart、analysis_options.yaml
